# 📚 Math+

Uma plataforma web educacional focada no aprendizado de matemática de forma simples, interativa e acessível.

O objetivo do projeto é auxiliar estudantes no aprendizado de diferentes conteúdos matemáticos através de módulos, quizzes, desafios e um sistema de progresso baseado em XP.

---

# 🖥️ Preview do Projeto

O **Math+** apresenta uma interface moderna para uma plataforma de educação matemática.

Na página inicial, o usuário encontra uma apresentação da plataforma, acesso aos conteúdos, sistema de progresso, desafios e opções para iniciar quizzes.

A plataforma também possui uma proposta relacionada à **ODS 4 — Educação de Qualidade** e **ODS 9 — Indústria, Inovação e Infraestrutura**, buscando incentivar o acesso à educação por meio da tecnologia.

# 🚀 Como Executar

## 1. Baixe ou clone o projeto

Caso o projeto esteja disponível em um repositório Git, utilize:

```bash
git clone URL_DO_REPOSITORIO
```

Ou apenas faça o download dos arquivos manualmente.

---

## 2. Abra o projeto

Após baixar ou clonar o projeto, abra a pasta no seu editor de código.

Para executar a plataforma, abra o arquivo:

```text

```

O `index.html` é a página principal do Math+ e permite o acesso às demais áreas da plataforma.

> É recomendado utilizar um servidor local, como o **Live Server** do Visual Studio Code, para uma melhor execução do projeto.

# 📈 Sistema de Progresso

O Math+ possui um sistema de progresso responsável por apresentar a evolução do estudante dentro da plataforma.

A interface utiliza uma barra de XP para representar quanto falta para alcançar o próximo nível.

### Exemplo apresentado no projeto

```text
Nível 7

Explorador Matemático

725 / 1000 XP
```

Além do nível, a interface apresenta estatísticas relacionadas ao progresso:

- 🔥 xp do usuário
- ✅ questões certas
- 📚 módulos feitos

---

# ⭐ Sistema de XP

O sistema de XP utiliza recompensas para incentivar o estudante a continuar realizando as atividades.

O usuário pode receber XP através de desafios e atividades.

### 🏆 Exemplos

| Atividade | XP |
|---|---:|
| Desafio diário completado | **25 XP** |
| Quiz Rápido — 5 questões | **50 XP** |
| Completar um módulo inteiro | **200 XP** |
| Sequência de 7 dias seguidos | **100 XP** |

Esse sistema transforma o progresso do estudante em uma experiência mais próxima de uma mecânica de jogo.

---

# 🎯 Desafios

A plataforma apresenta uma área de desafios que permite ao usuário acompanhar atividades concluídas e atividades que ainda precisam ser realizadas.

Entre os desafios apresentados estão:

- Desafio diário
- Quiz rápido
- Completar um módulo
- Sequência de 7 dias

Os desafios concluídos aparecem identificados visualmente, enquanto os desafios ainda não disponíveis são apresentados como bloqueados.

---

# 🧠 Quiz

O Math+ possui um sistema de quizzes para testar os conhecimentos adquiridos nos módulos.

A plataforma apresenta:

> **140+ questões**

O usuário pode acessar os quizzes através dos botões:

- **Começar a aprender**
- **Iniciar**

Também existe uma área de próximo desafio, como:

> **Quiz de Porcentagem**

O quiz permite utilizar os conhecimentos estudados nos módulos para resolver questões.

Após a realização do quiz, o usuário é direcionado para a página de resultado.

---

# 📊 Resultado

Após finalizar um quiz, o usuário pode visualizar o resultado da atividade através da página:

```text
resultado.html
```

Essa página é responsável por apresentar as informações relacionadas ao desempenho obtido pelo estudante na atividade.
